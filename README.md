# Portfólio | João Victor

Este é meu portfólio atualizado. Usei meu portfólio anterior como referência e mantive sua proposta, trazendo melhorias no design, na responsividade e na organização do conteúdo. Esta versão foi desenvolvida com tecnologias mais atuais, incluindo React e Bootstrap.

## Tecnologias

- React
- Vite
- Bootstrap
- CSS
- React Icons

## Executar localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
